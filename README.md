# Pico CSS Documentation

> **Pico CSS is no longer maintained.** This documentation stays online but will not be updated. [Read more](https://picocss.com/docs/maintenance)

Pico CSS uses [Remix](https://remix.run) for its documentation.

To run the project locally, first install the dependencies:

```bash
yarn
```

Next, run the development server:

```bash
yarn dev
```
